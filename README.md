# estudos_mobile
Repo de estudos para dart/flutter

Essa é a estrutura inicial para um projeto em Dart. Sempre para dar início a um projeto em Dart:

`dart create meu_app`

Ele vai iniciar com uma estrutura com import, parâmetros na função, etc., mas para executar um arquivo .dart, o mínimo necessário é ter a função void main, e um comando entre chaves. A main é responsável por executar uma aplicação em dart.

`void main(){ 
    print("Hello world"); 
}`

Obs.: Assim como no Java, cada linha/bloco de execução tem que ser dividido por ponto e vírgula no final.

Executando o comando via powershell

`dart run`

o app passa a executar.
