# Exercícios do curso

Resolva depois das aulas, em uma pasta de prática. Cada identificador `MNN-ENN` combina o módulo
e o exercício; o mesmo identificador leva ao gabarito. Tente por pelo menos 20 minutos antes de
consultar a solução. Guarde os comandos, as saídas e uma explicação do resultado.

Cada lista tem pelo menos 12 exercícios, dos quais no mínimo 8 são obrigatórios, distribuídos
entre fixação, aplicação, leitura de código, correção de bugs, implementação, revisão cumulativa
e desafio prático. Concluir um exercício significa conferir seus critérios, não apenas rodar algo.

## 🏷️ As categorias

O sufixo depois do `·` no título diz que tipo de trabalho o exercício pede. Isso importa: um
exercício de **Reflexão** que você "resolve" escrevendo código não foi resolvido.

| Categoria | O que se espera de você |
|---|---|
| **Fixação** | Repetir o que a aula mostrou, com dados diferentes |
| **Aplicação** | Usar o recurso num caso novo do app Foco |
| **Implementação** | Escrever uma peça inteira a partir do contrato |
| **Leitura de código** | Explicar o que um trecho faz, e por que |
| **Correção de bugs** | Achar e consertar um defeito descrito |
| **Diagnóstico** | Partir de um sintoma e chegar à causa |
| **Decisão** | Escolher entre alternativas e **justificar** |
| **Reflexão** | Resposta escrita; não há código a entregar |
| **Revisão cumulativa** | Combinar aulas diferentes do módulo |
| **Desafio prático** | Integrar o módulo inteiro num programa que roda |

## 🪟 Sobre o ambiente

Os exercícios assumem **Windows 11**, que é o ambiente do curso. Onde algo exige um Mac — parte
dos módulos 15 e 16 — o enunciado diz isso explicitamente e oferece o que dá para fazer no
Windows: editar os arquivos de configuração, rodar os verificadores e preparar o CI com runner
macOS.
