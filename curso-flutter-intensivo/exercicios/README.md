# Exercícios do curso

Resolva depois das aulas, em uma pasta de prática. Cada identificador `MNN-ENN` combina o módulo
e o exercício; o mesmo identificador leva ao gabarito. Tente por pelo menos 20 minutos antes de
consultar a solução. Guarde os comandos, as saídas e uma explicação do resultado.

Cada lista tem pelo menos 12 exercícios, dos quais no mínimo 8 são obrigatórios, distribuídos
entre fixação, aplicação, leitura de código, correção de bugs, implementação, revisão cumulativa
e desafio prático. Concluir um exercício significa conferir seus critérios, não apenas rodar algo.
